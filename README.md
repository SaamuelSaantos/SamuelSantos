## 👨‍💻 Sobre Mim

Olá! Meu nome é **Samuel Santos**. Sou apaixonado por tecnologia e atualmente **estudante de Desenvolvimento de Sistemas**. 

Utilizo este espaço como um laboratório pessoal e portfólio dinâmico. Meu objetivo é transformar a teoria da sala de aula em código real.

- 🎓 **Foco atual:** Construindo uma base sólida em programação por meio de estudos contínuos e projetos práticos.
- 💻 **O que estou explorando:** Python, Banco de Dados (MySQL) e Desenvolvimento Web (HTML, CSS, JavaScript).
- 🎯 **Meu objetivo:** Compreender como cada peça de software se conecta para criar soluções eficientes.

> 💡 *"Construindo conhecimento, uma linha de código por vez."*
